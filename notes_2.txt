==========What is JSX?=============
- Stands for JavaScript XML
- Allows us to write HTML in react
- JSX makes it easier to write and add HTML in React


====Coding JSX====
- JSX allows us to write HTML elemets in Js and place them in the DOM
without any createElement() and/or appendChild() methods
- Conversts HTML tags to react elements.

=====Expressions in JSX========
- With JSX we can write expressions inside curly braces{ }
*******************************main.jsx**********************
const myElement=<h1>React is {5+5} times betwer with JSX</h1>
************************************************************


=========Inserting a Large Block of HTML===========
- To write HTML on multiple lines, put the HTML inside parantheses.
- Start a project:
	cmd>> npm create vite@latest insertHTML -- --template react
************Example*****************
import { createRoot } from 'react-dom/client'

//multiple HTML lines
const myElement=(
  <ul>
    <li>Apples</li>
    <li>Banana</li>
    <li>Mango</li>
  </ul>
);

createRoot(document.getElementById('root')).render(
  myElement
)
***************************************

=======One Top Level Element======
- HTML code must be wrapped in ONE top level element.
Two paragraphs can be put in a <div> element:
***************************************
import { createRoot } from 'react-dom/client'

//multiple HTML lines
const myElement=(
  <div>
    <p>I am a paragraph</p>
    <p>Another Paragraph</p>
  </div>
);

createRoot(document.getElementById('root')).render(
  myElement
)

***************************************


==========Elements Must be Closed==========
- HTML elements must be properly closed
	const myElement=<input type="text"/>;
The element above is an open tag
*************************************************
import { createRoot } from 'react-dom/client'

//multiple HTML lines
const myElement=(
  <div>
    <input type="text" name="Name" /><br /> <br />
    <button>Click Me</button>
  </div>

  myElement

========Attribute class`=`className==============
- Class keyword is reserved in JavaScript.
- You are not allowed to use it in JSX
- We use className instead
Example:
	const myElement=<h1 className="myclass">Hello WOrld</h1>;
NOTE: className will be translated to class.


========JSX in React Components===========
- React uses components to build UIs.
- Components are independent and reusable bits of code.
- React Components are like JavaScript functions, and return HTML
- JSX works perfect inside React components.
****************main.jsx********************
import { createRoot } from 'react-dom/client'

function Car(){
  const brand="Ford";
  const model="Mustang";

  return (
    <>
    <h2>My Car</h2>
    <p>It is a {brand} {model}.</p>
    </>
  );
}

createRoot(document.getElementById('root')).render(
  <Car/>
)
**************************************************



========Expressions=============
- Most powerful feature of JSX.
- Ability to embed JS expressions directly within your markup.
- We use { } and our JS expressions in between it.
- React will evaluate expression and render the result in the DOM.
****************main.jsx******************
import { createRoot } from 'react-dom/client'

function Car(){
  return (
    <>
    <h1>My Car</h1>
    <p>It has {218*1.36} horsepower</p>
    </>
  );
}

createRoot(document.getElementById('root')).render(
  <Car/>
)
******************************************

=============Boolean Attributes===================
- Pass no value for an attribute, JSX treats it as true.
- True will make the button disabled, while false enabled.
	<button onClick={myfunc} disabled={true}>Hello World<button/>
	<button onClick={myfunc} disabled={false}>Hello World<button/>

=======The Style Attribute========
- Style attribute in JSX only accepts a JS object with camelCased CSS 
property names, rather than CSS string.
************main.jsx**************************
import { createRoot } from 'react-dom/client'

function Car(){
  const mystyles={
    color:"red",
    fontSize:"20px",
    backgroundColor: "lightyellow",
  };

  return (
    <>
      <h1 style={mystyles}>My Car</h1>
    </>
  )
}

createRoot(document.getElementById('root')).render(
  <Car/>
)
****************************************************
- The styles are stored in an object
- Style properties are written in camelCasing.



==========JSX If Statements=============
- They are control structures
- If block runs when condition evaluates to true
- React supports if statements, but not inside JSX
- Put if statements outside the JSX or use a ternary expression instead.
Option 1: Outside JSX:
************main.jsx**************************
import { createRoot } from 'react-dom/client'

function Fruit(){
  const x=5;
  let y="Apple";

  if (x<10){
    y="Banana";
  }

  return (
    <>
      <h1>{y}</h1>
    </>
  );
}

createRoot(document.getElementById('root')).render(
  <Fruit/>
)
**********************************************

Option 2: Ternary Expressions:
************main.jsx**************************
import { createRoot } from 'react-dom/client'

function Fruit(){
  const x=5;

  return (
    <>
      <h1>{(x)>10?"Banana":"Apple"}</h1>
    </>
  )
}
createRoot(document.getElementById('root')).render(
  <Fruit/>
)
**********************************************

======================Destructuring Props========================
- You can limit the properties a component receives by using destructuring.
***************main.jsx********************
import { createRoot } from 'react-dom/client'

function Car({color}){
  return (
    <>
      <h2>My car is a {color}</h2>
    </>
  );
}

createRoot(document.getElementById('root')).render(
  <Car brand="mustang" year="2023" color="Red"/>
)
*********************************************
- We limit the number of properties we require by only passing the color
property only.
- We use { } for destructuring.



==========Destructuring ...rest================
- When we don't know the number of properties received use the ...rest operator.
***************main.jsx********************
import { createRoot } from 'react-dom/client'

function Car({color, brand, ...rest}){
  return (
    <>
      <h2>My {brand} car is {color}. Year {rest.year}</h2>
    </>
  );
}

createRoot(document.getElementById('root')).render(
  <Car brand="mustang" year="2023" color="Red"/>
)

=============React Props Children===================
- In React, you can send the content between the opening and closing tags
of a component, to another component.
- Can be accessed in other components using the props.children property
***************main.jsx********************
import { createRoot } from 'react-dom/client'

function Son(props){
  return (
    <div style={{background: 'lightgreen'}}>
      <h2>Son</h2>
      <div>{props.children}</div>
    </div>
  );
}

function Daughter(props){
  const {brand, model}=props;

  return (
    <div style={{background: 'lightblue'}}>
      <h2>Daughter</h2>
      <div>{props.children}</div>
    </div>
  );
}

function Parent(){
  return (
    <div>
      <h1>My two Children</h1>
      <Son>
        <p>
          This was written in the parent Component,
          but displayed as part of the Son component
        </p>
      </Son>
      
      <Daughter>
        <p>
          This was written in the parent component, 
          but displayed as part of the Daughter Component.
        </p>
      </Daughter>
    </div>
  );
}

createRoot(document.getElementById('root')).render(
  <Parent/>
)
*********************************************



===========================React Events==============================
- Similar to HTML DOM events, React can perform actions based on user events
- React has the same events as HTML: click, change, mouseover etc

======Adding Events=====
- React events are written in camelCase.
	onClick
- React event handlers are written inside curly braces.
	onClick={shoot}
***************main.jsx********************
import { createRoot } from 'react-dom/client'

function Football(){
  const shoot=()=>{
    alert("Greet Shot!");
  }

  return (
    <button onClick={shoot}>Take the Shot</button>
  );
}

createRoot(document.getElementById('root')).render(
  <Football/>
)
*********************************************

- To pass an argument to an event handler use an arrow function
***************main.jsx********************
import { createRoot } from 'react-dom/client'

function Football(){
  const shoot=(a)=>{
    alert(a);
  }

  return (
    <button onClick={()=>shoot("Goal!")}>Take the Shot</button>
  );
}

createRoot(document.getElementById('root')).render(
  <Football/>
)
*********************************************
