==============Styling React Using CSS=============
- CSS styles:
	> inline styling

======Inline Styling======
- To style an element with the inline style attribute, the value must be
a JavaScript.
- We have to put them in two sets of curly{{}} braces because in JS expressions
are written in them.
************main.jsx****************
import { createRoot } from 'react-dom/client';
import { Suspense, lazy } from 'react';

const Header=()=>{
  return (
    <>
      <h1 style={{color:"red"}}>Hello Style</h1>
      <p>Add a little Style!</p>
    </>
  );
}

function App(){
  return (
    <div>
      <Header/>
      <h2 style={{color:"blue"}}>Who am I?</h2>
    </div>
  );
}

createRoot(document.getElementById('root')).render(
  <App />
);

===================React CSS Modules=====================
- CSS modules let you write CSS that is scoped locally to a specific component
- Prevents CSS class name conflicts and makes your styles more maintainable

======What are CSS Modules?========
- Are CSS files where class names are scoped locally by default.
- Needs the extension ".module.css". Import it after
*******************button.module.css*****************
.mybutton {
    padding: 10px 20px;
    border: none;
    border-radius: 4px;
    cursor: pointer;
    color: black;
    background-color: red;
}
*******************************************************

- Now import our module css file and use it to the specific component.
*******************main.jsx***************************
import { createRoot } from 'react-dom/client';
import styles from "./Button.module.css";

const App=()=>{
  return(
    <>
      <button className={styles.mybutton}>
        Click Me
      </button>
    </>
  )
}

createRoot(document.getElementById('root')).render(
  <App />
);

==============React CSS-in-JS===================
- Is a styling technique where you can write CSS direcly in your JS code
- Allows you to:
	> write CSS using JS
	> Create component-scoped styles
	> Use dynamic styles based on props
	> Avoid CSS class name conflicts
- Use the library: "styled-components"
	cmd>> npm install styled-components

- Write CSS inside .jsx files:
*******************main.jsx***************************
import { createRoot } from 'react-dom/client';

const MyHeader=styled.h1`

    <>
      <MyHeader> Welcome!</MyHeader>
    </>
  )

  <App />

================React Router======================
- Is a library that provides react routing capabilities for React Applications
- Routing means handling navigation between different views.
- Enables:
	> Create multiple pages in your single-page application
	> Handle URL parameters and query strings
	> Manage Browser history and navigation
	> Create nested routes and layouts
	> Implement protected routes for authentication.
- Without a router, our react will be limited to a single page with no
way to navigate between different views.



=======Install React Router=======
	cmd>> npm install react-router-dom


=====Wrap Your App with BrowserRouter=====
- Your application must be wrapped with the BrowserRouter component to
enable routing.
**************************
function App(){
  return(
    <BrowserRouter>
      {/*You App content Here */}
    </BrowserRouter>
  );
}
**************************

=====Create Views======
- Create three pages(or views) in our application:
	1. Home

- Create all three views in the same file for simplicity, but you can
of course split them into separate files.
****************main.jsx********************
function Home(){
  return <h1>Home Page</h1>;
}

function About(){

=============Basic Routing================
- React Router uses three main components for basic routing
	> Link: Creates navigation links that update the URL
	> Routes: A container for all your route definitions
	> Route: Defines a mapping between a URL path and a component.
- Add navigation links and routes for each link.
****************main.jsx********************
import { createRoot } from 'react-dom/client';
import { BrowserRouter, Routes, Route, Link } from 'react-router-dom';

function Home() {
  return <h1>Home Page</h1>;
}

function About() {
  return <h1>About Page</h1>;
}

function Contact() {
  return <h1>Contact Page</h1>;
}

function App() {
  return (
    <BrowserRouter>
      {/* Navigation */}
      <nav>
        <Link to="/">Home</Link> |{" "}
        <Link to="/about">About</Link> |{" "}
        <Link to="/contact">Contact</Link>
      </nav>

      {/* Routes */}
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
        <Route path="/contact" element={<Contact />} />
      </Routes>
    </BrowserRouter>
  );
}

createRoot(document.getElementById('root')).render(
  <App />
);
********************************************
- In the above example:
	> BrowserRouter: wraps your app and enables routing functionality
	> Link: components create navigation links
	> Routes and Route define your routing configuration.



=========Nested Routes================
- You have a route inside another Route--> nested routing
- Nested routes allow you change parts of the page when you navigate
to a new URL while other parts is not changed or reloaded--> Having a
page within a page.
- Example: add two new components that will be rendered inside the products
component.
One called CarProducts and one called BikeProducts:
****************main.jsx********************
import { createRoot } from 'react-dom/client';
import { BrowserRouter, Routes, Route, Link, Outlet } from 'react-router-dom';

function Home() {
  return <h1>Home Page</h1>;
}

function Products(){
  return (
    <div>
      <h1>Products Page</h1>
      <nav style={{marginBottom: '20px'}}>
        <Link to="/products/car">Cars</Link> | {" "}
        <Link to="/products/bike">Bikes</Link> | {" "}
      </nav>
      <Outlet/>
    </div>
  );
}

function CarProducts(){
  return(
    <div>
      <h2>Cars</h2>
      <ul>
        <li>Audi</li>
        <li>BMW</li>
        <li>Volvo</li>
      </ul>
    </div>
  );
}

function BikeProducts(){
  return (
    <div>
      <h2>Bikes</h2>
      <ul>
        <li>Suzuki</li>
        <li>Yamaha</li>
        <li>Honda</li>
      </ul>
    </div>
  );
}

function Contact() {
  return <h1>Contact Page</h1>;
}

function App() {
  return (
    <BrowserRouter>
      {/* Navigation */}
      <nav>
        <Link to="/">Home</Link> |{" "}
        <Link to="/products">Products</Link> |{" "}
        <Link to="/contact">Contact</Link>
      </nav>

      {/* Routes */}
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/products" element={<Products />}>
          <Route path='car' element={<CarProducts/>}/>
          <Route path='bike' element={<BikeProducts/>}/>
        </Route>
        <Route path="/contact" element={<Contact />} />
      </Routes>
    </BrowserRouter>
  );
}

createRoot(document.getElementById('root')).render(
  <App />
);
********************************************
1. Outlet:
- <Outlet/> element in the products component specifies where to render
the child route's content

2. Routes:
- The routes element contains the routes to CarProducts and BikeProducts as
child routes of the Products parent route.

3. URL Structure:
- The URL structure is relative to the parent route's path. E.G
	> "products/car" the CarProducts component is rendered.


=============Style Active Links==============
- Special Link component called NavLink. Knows whether the link's URL
is active or not
- NavLink is especially useful for:
	> Navigation Menus
	> BreadCrumbs
	> Tabs
- A NavLink is considered active if the current URL matches its to prop



================URL Parameters================
- Variables that can add data to your components
- Are used to pass data between components.
****************main.jsx********************
import { createRoot } from 'react-dom/client';
import { BrowserRouter, Routes, Route, Link, Outlet, useParams } from 'react-router-dom';

=======================React Transitions======================
What is useTransition?
- Helps you keep your React app responsive during heavy updates.
- Mark states as non-urget and other allowed as more urgent during updates.


======When to Use Transitions=========
- When you have:
	> A slow operation that might freeze UI
	> Updates that aren't immediately critical
	> Search results that take time to display


======Basic Example====
- useTransition hook returns two items:
	> isPending: tells you if a transition is active
	> startTransition: function to mark updates as transitions
***************main.jsx****************************
import { createRoot } from 'react-dom/client';
import { useState, useTransition } from 'react';

function SearchResults({query}){
  //Simulate slow search results
  const items=[];
  if(query){
    for(let i=0; i<1000;i++){
      items.push(<li key={i}>Result for {query}-{i}</li>);
    }
  }
  return <ul>{items}</ul>
}

function App() {
  const [input, setInput]=useState('');
  const [query, setQuery]=useState('');
  const [isPending, startTransition]=useTransition();

  const handleChange=(e)=>{
    //Urgent: Update input field
    setInput(e.target.value);

    //Non-Urgent: Update search results
    startTransition(()=>{
      setQuery(e.target.value);
    });
  };

  return (
    <div>
      <input
       type="text"
       value={input}
       onChange={handleChange}
       placeholder='Type to search'
      />
      {isPending && <p>Loading Results...</p>}
      <SearchResults query={query}/>
    </div>
  );
}

createRoot(document.getElementById('root')).render(
  <App />
);
